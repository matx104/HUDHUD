# AWARDS — The Six Prize Lanes

> Official register (from the Innovation Studio rules page, received 2026-10-15). Winners announced **Nov 20, 2026**. One winning team per category, and one project takes home at most **one Grand Prize and one Category Prize** (Official Rules §4.2, §8; task.md). All cash prizes ship as e-Gift Cards (Hackathon Rules §8.3), split equally among team members — **I'm solo, so every package lands undivided.**

## 🏆 Grand Prize — First Place
- **~$4,000 cash** per member
- One digital ticket to a Premier League game (~$1,000 value) per member
- PL store voucher ($50) per member
- Feature in social promotion
- **For:** the most complete and compelling solution — innovative use of the Microsoft AI platform stack, meaningful explainable match intelligence, engaging narratives, contextual insights, accessible and personalized experiences
- Solo FMV: **~$5,050**

## 🏆 Grand Prize — Second Place
- **~$2,500 cash** per member + ticket + voucher + social feature
- Same criteria as First
- Solo FMV: **~$3,550**

## 🧠 Best Use of Microsoft Foundry
- **~$1,500 cash** per member + voucher + social feature
- **For:** most effective leverage of Foundry — development, orchestration, and management of AI-powered solutions; faster innovation, developer productivity, scalable AI experiences "difficult to achieve through traditional approaches alone"
- Solo FMV: **~$1,550**

## 💼 Best Enterprise Solution
- **~$1,500 cash** + voucher + feature
- **For:** strongest enterprise-deployment readiness and long-term business impact — clear path to adoption, reliability, transparency, and production controls
- Solo FMV: **~$1,550**

## 💡 Best Multi-Agent Orchestration
- **~$1,500 cash** + voucher + feature
- **For:** purposeful multi-agent collaboration (GitHub Copilot, Microsoft Agent Framework, A2A, or other) — distinct roles, shared state, effective handoffs, **recovery from failures**, end-to-end outcome a single agent couldn't achieve
- Solo FMV: **~$1,550**

## 🎨 Best Azure Cloud-Native Integration
- **~$1,500 cash** + voucher + feature
- **For:** Azure cloud-native services (AKS, Container Apps, Functions, Logic Apps, AI-optimized data platforms) — scalable, resilient, event-driven, operational excellence
- Solo FMV: **~$1,550**

## Built for every lane, capped by the rules (solo)

- Every lane is built to win: the same build aims at all six (goals.md maps each award to the features that earn it). What one project takes home is capped by the rules, and which lanes it wins is the judges' call.
- The most one entry can take home: Grand Prize First Place + one category prize: **~$5,500 cash + PL ticket + 2× voucher + social features ≈ $6,600 FMV**
- The submission names **Best Use of Microsoft Foundry** as its category (docs/submission.md)
