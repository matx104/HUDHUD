The asks, answered — I

Explainable match intelligence

The ask: not "AI says X dominated", but why — with event evidence.

Delivered
The Scout flags the moments that matter; every line that airs carries the events it stands on, each number recomputed by the Critic before it airs.
How
Code counts, models write: deterministic detection on a sub-millisecond hot path; the Narrator drafts from a fact sheet on Foundry; the Critic refuses what it can't prove, on screen, with the reason.
Next
The decision explainer — the referee's call explained with the Law it rests on — then fouls read from camera angles, every prediction citing its frames.

Real-time narratives

The ask: live during the match, not only after it.

Delivered
A live cue stream, start to finish: alert to air in about 1.3 seconds. With the Narrator knocked out mid-match in tests, the broadcast aired the Scout's cited facts, said so, and announced the recovery — never dark.
How
The hot path never waits on a model; each alert runs Narrator → Critic → Localizer as a Microsoft Agent Framework workflow with a rewrite edge and an orchestrator-supervised fallback.
Next
The same cue contract behind a broadcaster's own graphics system; multi-match coverage from one deployment.

Automated recaps

The ask: the 90-minute story writes itself.

Delivered
At full time the match writes its own recap — result, goals, both sides' numbers — every line through the Critic first, as a page that prints to PDF (a sample ships in this kit).
How
One rule lifted at full time — the checker may look back over the whole match — with the same evidence law as the live lines.
Next
A momentum timeline and player cards; a recap assembled per viewer, in their language and their club's colours.

Personalized experiences

The ask: the analyst and the casual fan as two genuinely different experiences.

Delivered
HUD²'s three lenses — referee, commentator, fan — Ask the match, a club, a player or one number to follow, casual or analyst modes. Emphasis changes; the facts never do.
How
Personalisation is a layer over verified cues: the viewer's choice reorders and colours what airs, and the Critic checks every viewer's line the same way.
Next
HUD² worn — the same lenses on glasses, marks on the real pitch — as the hardware allows.

The asks, answered — II

Multi-language storytelling

The ask: insight for fans around the world, in multiple languages.

Delivered
Every verified line airs in English, Urdu or Arabic — on screen and spoken by Azure AI Speech. Questions asked out loud in any of the three come back checked, in the same language.
How
The Localizer translates under the same law: no number the checked line doesn't state, every name kept as written. A breaking translation airs the English instead.
Next
More languages ride the same rail — the law doesn't change, only the voice.

Data innovation

The ask: synthetic, football-realistic data only (§4.7) — created and extended.

Delivered
A seeded synthetic generator — invented clubs, real-match volumes — with a committed JSON Schema contract, hidden ground truth, and a published realism check against 7,559 real internationals. Same seed, same match: every number reproducible.
How
Calibration over 100 seeds; realism scored against a public-domain results record, used only as a benchmark; the limits stated plainly.
Next
Richer event types and playing styles; the audit trail mirrored into Microsoft Fabric's OneLake — weighed and deferred to stay inside the free tier.

Ask the match anything

The ask, in the grand-prize lane's own words: ask the match anything, and get a checked answer.

Delivered
Any question, live or after full time, in three languages, typed or spoken: the model must call counting tools for every number, the Critic recomputes each one, and every answer is sealed into the match ledger with a proof the browser checks.
How
Function calling on Foundry; each count a fact with an id; Foundry's judges scored the answers 5.0 of 5 on unseen matches after the first run's fix.
Next
Questions over a whole season of ledgers, each answer cited to the exact block that sealed it.

Recovery from failure

The ask, from the multi-agent lane: recovery from failures — an outcome no single agent could achieve.

Delivered
Five agents, distinct roles, shared match state. A test knocks the Narrator out four times in a row mid-match and the cues never stop; the studio's off-air switch does it on camera. The Critic serves assistants over MCP and agents over A2A.
How
The Orchestrator retries once, falls back to detection-only cues marked unverified, and announces recovery on air. The Critic runs no model, so its verdicts are computed and can't be talked round.
Next
The Critic as a shared court: the same checks opened to other broadcasters' agents.

The hero technologies, in the build

Named by the challenge, weighed by the judges, live in this entry:

GitHub
Copilot agent mode in the build daily, working from the repository's own evidence rules, so it follows the same law the agents do.
Foundry
gpt-4.1-mini writes the lines, gpt-5-mini backs it up; Foundry's evaluators judged what aired (groundedness 4.84 of 5); every call traced with its tokens and its cost.
Agents
The warm path is a Microsoft Agent Framework workflow; the Critic serves assistants over MCP (six read-only tools) and other agents over A2A, with no model inside.
Azure data
The audit trail on Cosmos DB's free tier, kept 90 days; Microsoft Fabric weighed for the analytics and deferred — recorded in Data innovation's next.
Cloud-native
One image on Container Apps with a managed identity and no keys; Application Insights traces every agent step; a read-only doctor checks the whole of it.

Every row names its evidence. The road from here — the decision explainer, perception, the fourth official — is written down, gate by gate.
